# 阿秀礼簿 - 人情往来记账微信小程序

## 项目简介

一款免费、无广告的人情往来记账微信小程序，所有数据存储在本地，不上传服务器。

## 功能特性

- ✅ **礼簿管理**：为婚宴、寿宴等场合创建独立礼簿
- ✅ **收礼记录**：姓名联想输入、同名提醒、现金/微信区分
- ✅ **送礼记录**：按年份筛选、今日/本周/本月/全年统计
- ✅ **人员往来**：自动计算与每个人的人情结余
- ✅ **全局检索**：搜索礼簿、收礼、送礼记录，关键词高亮
- ✅ **数据可视化**：条形图 + 扇形图展示统计数据
- ✅ **密码锁**：保护隐私数据安全

## 技术栈

- 原生微信小程序（WXML + WXSS + JavaScript）
- 本地存储（wx.Storage）
- Canvas 图表绘制

## 如何在个人电脑上运行

### 1. 下载微信开发者工具

访问官方下载页面：
```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

下载 **Windows 64 稳定版** 并安装。

### 2. 导入项目

1. 打开微信开发者工具
2. 点击「+」→「导入项目」
3. 选择本文件夹（myNodepad）
4. AppID 已配置：`wxea53fe4d912f5525`
5. 点击「导入」

### 3. 运行调试

导入成功后，工具会自动编译并显示预览界面。

- 点击「编译」按钮重新编译
- 点击「预览」生成二维码，用手机扫码预览
- 点击「真机调试」在真实手机上调试

### 4. 上传代码

1. 在微信开发者工具中，点击右上角「上传」
2. 填写版本号和备注
3. 登录微信公众平台：https://mp.weixin.qq.com
4. 在「版本管理」中提交审核

## 注意事项

1. **小程序名称**：在微信公众平台设置为「阿秀礼簿」
2. **类目选择**：建议选择「工具 → 记账」
3. **隐私协议**：选择「不收集用户信息」
4. **首次审核**：可能需要 1-3 个工作日
